# DataPrep Kit (`kit_estadistica`)

Una librería básica de Python para el procesamiento, discretización (Igual Anchura e Igual Frecuencia), normalización y estandarización de datos. También permite el cálculo de distintas métricas, tales como la Varianza, Entropia, ROC/AUC e Información Mutua; y la visualización de las últimas dos métricas.

## Instalación

```bash
pip install .
```
